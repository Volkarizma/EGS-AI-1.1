# Friendly Assistant (EGS AI 1.1)

**Friendly Assistant (EGS AI 1.1)** is a web-based voice and text interaction software specially designed for individuals with special needs. Developed by **Egemen Şeker**, this application provides users with an accessible, structured, and supportive digital environment.

Engineered with accessibility standards as its primary focus, the system offers an intuitive interface, multi-modal communication (voice and text), and structured AI responses tailored for user comfort and usability.

## Key Features

### Accessibility Capabilities

* **Font Size Controls:** Allows dynamic scaling of text size (A+ / A-) to accommodate visually impaired users.
* **High Contrast Mode:** Provides a high-contrast theme (yellow text on black background) to assist users with visual sensitivities or low vision.
* **Speech Rate Adjustments:** Offers selectable speech synthesis playback speeds (Normal, Very Slow, Fast) to ensure optimal comprehension.
* **Mute Controls:** Enables users to instantly suppress audio outputs as needed.

### Interaction Models

* **Voice Input (Speech-to-Text):** Captures user voice commands through native browser speech recognition interfaces.
* **Audio Synthesis (Text-to-Speech):** Converts assistant text outputs into spoken speech automatically.
* **Audio Replay:** Allows users to re-listen to previous assistant responses on demand.

### Quick Prompts

Pre-configured, single-tap options designed for simplified communication and daily guidance:

* **Daily Planning:** Structured activity recommendations.
* **Emotional Self-Assessment:** Guidance for identifying and articulating emotional states.
* **Assistance Requests:** Immediate reassuring instructions for overwhelming situations.
* **Daily Routines:** Sequential reminders for daily structure.
* **Weather and Attire:** Practical recommendations regarding daily weather and clothing options.
* **Daily Affirmations:** Positive messages aimed at reducing anxiety.

## Technical Stack

* **Frontend Framework:** HTML5, Modern JavaScript (ES6+)
* **Styling:** Tailwind CSS
* **Iconography:** Phosphor Icons Library
* **Browser APIs:**
  * `SpeechRecognition` Interface (Voice Input)
  * `SpeechSynthesis` Interface (Voice Output)

## Deployment and Execution

The project operates as a lightweight, single-file client-side application (`egs.ai_1.1.html`). No dedicated server infrastructure or complex installation process is required.

1. Clone the repository:

   ```
   git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
   ```

2. Open `egs.ai_1.1.html` in any supported web browser (e.g., Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).
